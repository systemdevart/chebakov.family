# Семейное древо Чебаковых

Интерактивное семейное древо с визуализацией, хронологией и картой миграции.

## Запуск

```bash
npm install
npm run dev
```

## Возможности

- **Древо** — интерактивный граф с зумом и навигацией
- **Хронология** — временная шкала жизни поколений
- **Карта** — география семьи на карте
- **Админка** (`/admin`) — редактирование данных
